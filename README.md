# simple-price-scraper

Sample build — track prices across product pages into one CSV.

```
echo "https://example.com/product" >> urls.txt
python scrape.py   # appends timestamped title + price rows to prices.csv
```

No heavy dependencies, polite request pacing. Want this pointed at your
shop, your competitors, or a whole catalogue — with alerts when prices move?
